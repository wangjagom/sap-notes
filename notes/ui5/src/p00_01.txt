@kw 자바스크립트
d: 웹 페이지를 움직이게 만드는 프로그래밍 언어예요. 버튼 반응, 입력값 검사, 서버 데이터 표시가 모두 자바스크립트로 이뤄져요.
e: 웹 페이지는 세 가지 재료로 만들어요. HTML은 화면에 무엇이 있는지, CSS는 어떻게 보일지, 자바스크립트는 어떻게 움직일지를 정해요.
tb:
재료 | 하는 일 | 집으로 말하면
HTML | 화면에 무엇이 있는지 정해요 (글, 버튼, 테이블) | 뼈대와 방 구조
CSS | 어떻게 보일지 정해요 (색, 크기, 위치) | 인테리어
자바스크립트 | 어떻게 움직일지 정해요 | 전기 배선과 스위치
.
s: 브라우저가 읽고 바로 실행해요. 위에서 아래로 한 줄씩 실행돼요.
w: 이름이 비슷한 자바(Java)와는 다른 언어예요.
s: SAPUI5에서는 화면에 무엇을 놓을지는 UI5 부품으로 적고, 화면이 하는 일은 자바스크립트로 써요.

@kw 콘솔(Console)
d: 코드를 바로 실행해 보고, 코드가 남기는 메모와 에러를 보여 주는 창이에요. 크롬에서 F12 → Console 탭으로 열어요.
e: 코드를 이해하는 가장 빠른 방법은 값을 직접 찍어 보는 거예요. "이 값이 뭐지?"를 상상하지 말고 콘솔에 찍어서 확인해요.
c:js
console.log("안녕");           // 안녕
console.log(1 + 2);            // 3
console.log(typeof "민수");    // string
.
s: `console.log(값)`은 괄호 안의 값을 콘솔에 보여 줘요. `typeof 값`은 그 값의 종류를 알려 줘요.
s: 붙여넣기가 막히면 `allow pasting`을 입력하고 Enter를 누른 뒤 다시 붙여넣어요. 화면을 비우려면 `console.clear()`를 입력해요.

@kw 라이브러리 · 프레임워크
d: 라이브러리는 필요할 때 꺼내 쓰는 도구 모음이고, 프레임워크는 앱의 뼈대와 규칙을 미리 정해 둔 틀이에요. SAPUI5는 프레임워크예요.
tb:
 | 라이브러리 | 프레임워크
비유 | 공구함 | 인테리어가 끝난 방
내가 하는 일 | 필요한 공구를 골라 직접 써요 | 정해진 자리에 내 코드를 놓아요
부르는 쪽 | 내가 도구를 불러요 | 틀이 내 코드를 불러요
예 | Math, UI5의 sap.m | SAPUI5
.
c:js
console.log(Math.max(3, 9));    // 9   가장 큰 수
console.log(Math.round(2.6));   // 3   반올림
.
e: UI5는 앱을 화면(View), 동작(Controller), 데이터(Model)로 나눠 만든다는 규칙이 정해져 있어요. 앱을 시작하고 화면을 띄우는 일은 UI5가 해요. 그래서 내가 직접 실행하지 않았는데 내 코드가 실행되는 일이 생겨요.
w: 프레임워크는 규칙이 있어서, 파일 이름이나 위치를 규칙과 다르게 쓰면 앱이 열리지 않아요(6부 폴더 구조).
s: 수업에서 "UI5 라이브러리"라고 하면 `sap.m` 같은 UI5 안의 부품 모음을 가리키는 경우가 많아요.

@kw 자주 보는 에러 세 가지
d: 에러 메시지는 모양이 거의 정해져 있어요. 아래 세 가지만 알아도 대부분 읽혀요.
c:js
console.log(sName);        // ReferenceError: sName is not defined
console.log("안녕);        // SyntaxError: Invalid or unexpected token
"안녕"();                   // TypeError: "안녕" is not a function
.
tb:
에러 메시지 | 한마디로 | 흔한 원인
`is not defined` | 그런 이름이 없어요 | 이름 오타, 아직 만들지 않은 이름
`Invalid or unexpected token` | 문법이 깨졌어요 | 따옴표나 괄호를 열고 안 닫음
`is not a function` | 함수가 아닌 값을 함수처럼 불렀어요 | 이름 오타, 값의 종류가 예상과 다름
.
s: 메시지 오른쪽의 파일 이름과 줄 번호(`script.js:42`)를 누르면 문제가 난 줄로 바로 가요.
w: 빨간 에러가 여러 개면 맨 위의 것부터 봐요. 아래 에러는 대부분 첫 에러 때문에 줄줄이 생겨요.

@ch ch-1 | 1부 | 값과 데이터의 모양 | 프로그램은 값을 저장하고, 비교하고, 꺼내 쓰는 일의 반복이에요. 값을 다루는 기본기를 배워요.

@kw 변수
d: 값을 담아 두는 이름 붙은 상자예요. `const`는 다시 넣을 수 없는 상자, `let`은 다시 넣을 수 있는 상자예요.
l: 상자에 이름표(변수 이름)를 붙여 두면, 나중에 이름으로 값을 꺼낼 수 있어요.
t:
const 변수이름 = 값;
let 변수이름 = 값;
변수이름 = 새 값;
.
c:js
const sName = "민수";         // 상자를 만들고 "민수"를 넣어요
let nCount = 0;               // 상자를 만들고 0을 넣어요
nCount = nCount + 1;          // 상자 안의 값을 1로 바꿔요
console.log(sName, nCount);   // 민수 1
.
s: 다시 넣을 일이 없으면 `const`를 써요. 실수로 값을 바꾸는 일을 막아 줘요.
s: `=`는 수학의 "같다"가 아니라 "오른쪽 값을 왼쪽 상자에 넣어라"라는 뜻이에요. 상자를 만드는 일은 선언(Declare), 값을 넣는 일은 할당(Assign)이라고 해요.
w: `const` 변수에 값을 다시 넣으면 `Assignment to constant variable` 에러가 나요. 바꿀 값은 처음부터 `let`으로 만들어요.
s: 콘솔에서 같은 이름을 `const`나 `let`으로 또 만들면 `has already been declared` 에러가 나요. 새로고침하고 다시 실행해요.

@kw 자료형(Data Type)
d: 값의 종류예요. 종류에 따라 할 수 있는 일이 달라요. `typeof`로 확인해요.
tb:
자료형 | 예 | typeof 결과
문자열 (string) | `"CL303"`, `"2"` | `"string"`
숫자 (number) | `2`, `370000` | `"number"`
불리언 (boolean, 참/거짓) | `true`, `false` | `"boolean"`
값 없음 | `undefined` (아직 안 넣음), `null` (일부러 비움) | `"undefined"`, `"object"`
객체, 배열 | `{ name: "민수" }`, `[1, 2, 3]` | 둘 다 `"object"`
.
c:js
typeof "2"    // "string"
typeof 2      // "number"
.
w: `"2"`(문자)와 `2`(숫자)는 화면에서 똑같아 보여도 다른 값이에요. 값이 이상하면 `typeof`로 종류부터 확인해요.
s: `null`의 결과가 `"object"`인 건 자바스크립트의 오래된 특이점이에요. 외울 필요는 없어요.

@kw 문자열
d: 따옴표로 감싼 글자 값이에요. 쌍따옴표, 홑따옴표, 백틱 세 가지가 있어요.
tb:
따옴표 | 모양 | 특징
쌍따옴표 | `"안녕"` | 가장 기본이에요. 이 노트는 이걸 써요
홑따옴표 | `'안녕'` | 쌍따옴표와 똑같이 동작해요
백틱 | `` `안녕` `` | `${ }`로 값을 끼워 넣을 수 있어요
.
c:js
const sName = "민수";
const nScore = 85;
"안녕, " + sName + "!"            // "안녕, 민수!"   +로 이어 붙여요
`안녕, ${sName}!`                 // "안녕, 민수!"   백틱 안에 ${ }로 끼워 넣어요
`합계는 ${nScore + 10}점이에요`    // "합계는 95점이에요"   ${ } 안에서 계산도 돼요
.
w: `${ }`는 백틱 안에서만 동작해요. 쌍따옴표 안에서는 `"${nScore}"`가 그냥 글자로 나와요.
s: 붙일 게 많을수록 백틱이 읽기 쉬워요. 백틱은 키보드 왼쪽 위, 숫자 1 옆에 있어요.
m: 더 알아보기: 글자 안에 따옴표 쓰기, 여러 줄 글자
감싸는 따옴표와 다른 종류를 안에 쓰면 돼요. 같은 따옴표를 쓰려면 앞에 역슬래시(`\`)를 붙여요.
c:js
"그는 '안녕'이라고 했어요"
'그는 "안녕"이라고 했어요'
"그는 \"안녕\"이라고 했어요"
"그는 "안녕"이라고 했어요"      // ❌ SyntaxError: 글자가 중간에 끝나 버려요
.
백틱은 줄바꿈도 그대로 넣을 수 있어요.
c:js
const sText = `첫째 줄
둘째 줄`;
.
/m

@kw ===
d: 값과 종류가 모두 같을 때만 같다고 봐요. 비교는 항상 `===`, 다르다는 `!==`를 써요.
c:js
"2" == 2    // true   ← == 는 종류를 몰래 맞춰서 비교해요
"2" === 2   // false  ← === 는 종류까지 비교해요
"2" !== 2   // true   ← !== 는 "다르다"예요
.
w: `==`는 쓰지 않아요.

@kw 형 변환
d: 문자와 숫자 사이를 바꾸는 거예요. `Number(값)`은 숫자로, `String(값)`은 문자로 바꿔요.
c:js
Number("2")     // 2      문자 → 숫자
String(2)       // "2"    숫자 → 문자
"0" + 1         // "01"   문자 + 숫자는 이어 붙이기예요
.
w: 입력창에 적은 값은 숫자처럼 보여도 항상 문자열이에요. 계산하거나 숫자와 비교하려면 `Number(값)`으로 바꿔요. `"10" + 5`는 `15`가 아니라 `"105"`예요.

@kw 객체(Object)
d: 관련된 값을 이름표(키)를 붙여 한 상자에 담은 거예요. 키로 바로 찾아가요.
t:
const 객체이름 = {
    키1: 값1,
    키2: 값2
};
객체이름.키1
.
c:js
const oStudent = {
    name: "민수",
    group: 2,
    score: 85
};
oStudent.name          // "민수"   점으로 꺼내기
oStudent["name"]       // "민수"   대괄호로도 꺼낼 수 있어요
oStudent.score = 90;   // 값 바꾸기
oStudent.nick = "수니"; // 없던 키 추가
oStudent.age           // undefined   없는 키는 undefined
.
s: 이름표는 키(Key), 담긴 것은 값(Value), 키와 값 한 쌍은 프로퍼티(Property)라고 해요.
s: `const`로 만든 객체도 안의 값은 바꿀 수 있어요. 상자 자체가 아니라 내용물만 바꾸는 거라서요.
w: 없는 키는 `undefined`예요. 그 `undefined`에서 또 꺼내면 `Cannot read properties of undefined` 에러가 나요. 앞으로 가장 자주 만날 에러예요.
c:js
oStudent.age            // undefined
oStudent.age.year       // TypeError: Cannot read properties of undefined (reading 'year')
.
m: 더 알아보기: 키를 글자로 쓰기, 따옴표가 필요한 키
키는 사실 문자열이에요. 따옴표를 생략해도 되는 것뿐이에요. 키에 공백이나 `-`가 있으면 따옴표로 감싸고, 꺼낼 때도 대괄호를 써요.
c:js
const oUser = { "first-name": "민수" };
oUser["first-name"]      // "민수"
oUser.first-name         // ❌ "first 빼기 name"으로 읽혀요
.
/m

@kw 배열(Array)
d: 값을 줄 세워 놓은 거예요. 각 값에는 0부터 시작하는 번호(인덱스)가 붙어요.
t:
const 배열이름 = [값1, 값2, 값3];
배열이름[번호]
.
c:js
const aGroups = [1, 2, 3];
aGroups[0]          // 1      번호는 0부터 시작해요
aGroups.length      // 3      값이 몇 개인지
aGroups.push(4);    // [1, 2, 3, 4]   맨 뒤에 추가
aGroups[aGroups.length - 1]   // 4    마지막 값
.
s: 번호는 인덱스(Index), 값 하나하나는 요소(Element), 개수는 길이(Length)라고 해요.
s: `push`처럼 점(`.`)으로 붙여 쓰는 기능을 메서드라고 해요(4부).
w: 첫 번째 값은 `[1]`이 아니라 `[0]`이에요. 없는 번호를 부르면 에러가 아니라 `undefined`가 나와요.

@kw 배열 안의 객체, 객체 안의 배열
d: 실제 데이터는 대부분 객체와 배열이 섞인 모양이에요. 왼쪽에서 오른쪽으로 한 단계씩 읽어요.
c:js
const oClass = {
    title: "3반",
    studentList: [                       // 객체 안에 배열
        { id: "S01", name: "민수" },     // 배열 안에 객체 (0번)
        { id: "S02", name: "지아" }      // (1번)
    ]
};
oClass.studentList[1].name    // "지아"
.
e: `oClass` 안의 `studentList`, 그 안의 1번, 그 안의 `name` 순서로 읽어요. 한 번에 읽기 어려우면 `console.log`로 한 단계씩 끊어서 찍어 봐요.

@kw 변수 이름 접두어(헝가리안 표기)
d: 변수 이름의 첫 글자로 값의 종류를 표시하는 습관이에요. 자바스크립트 규칙은 아니에요.
tb:
접두어 | 뜻 | 예
`s` | string (문자열) | `sName`, `sCode`
`n`, `i` | number (숫자), integer (정수) | `nCount`, `iIdx`
`b` | boolean (참/거짓) | `bFound`
`a` | array (배열) | `aGroups`
`o` | object (객체) | `oStudent`
`fn` | function (함수, 3부) | `fnCallback`
.

@kw JSON
d: 객체를 글자로 적어 두는 약속된 형식이에요(JavaScript Object Notation). `data.json` 파일로 저장하거나 데이터를 주고받을 때 써요.
w: 객체보다 규칙이 엄격해요. 키도 반드시 쌍따옴표, 마지막 항목 뒤 쉼표 금지, 주석(`//`) 금지예요. 오타가 하나만 있어도 전체를 못 읽어요.
c:js
{ "name": "민수", "score": 85 }
.
m: 더 알아보기: 객체와 JSON 글자 서로 바꾸기
c:js
const sJson = JSON.stringify({ name: "민수", score: 85 });   // 객체 → 글자
JSON.parse(sJson)                                           // 글자 → 객체
.
UI5에서는 JSON 파일을 모델이 알아서 읽어 줘서 직접 바꿀 일이 많지 않아요.
/m
