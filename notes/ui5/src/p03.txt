@ch ch-3 | 3부 | 함수 | 함수는 코드 덩어리에 이름을 붙여 둔 거예요. 값을 받아서 처리하고, 결과를 돌려줄 수 있어요.

@kw function
d: 코드를 묶어 이름을 붙여요. 만들기만 하면 실행되지 않고, 이름 뒤에 `()`를 붙여 불러야 실행돼요.
l: 자판기와 비슷해요. 동전을 넣으면(입력) 음료가 나와요(결과).
t:
function 함수이름(매개변수) {
    실행할 코드;
    return 돌려줄 값;
}
const 결과 = 함수이름(인자);
.
c:js
function getGroupName(nGroup) {
    return nGroup + "조";
}
const sGroupName = getGroupName(2);     // 2를 넣고 불렀더니 "2조"가 돌아와요
console.log(sGroupName);                // 2조
.
s: 받는 칸은 매개변수(Parameter), 부를 때 넣는 값은 인자(Argument)예요. 현장에서는 둘 다 그냥 "파라미터"라고 부르는 경우가 많아요. 여러 개면 쉼표로 이어요: `add(1, 2)`
s: 돌려주는 결과는 반환값(Return Value)이에요. `return`이 없으면 함수는 `undefined`를 돌려줘요. 일만 하고 돌려줄 게 없는 함수는 `return`이 없어도 돼요.

@kw return으로 일찍 끝내기
d: 조건이 안 맞으면 `return;`으로 함수를 바로 끝내요. 안쪽으로 계속 들여 쓰는 것보다 읽기 쉬워요.
c:js
function register(sName) {
    if (!sName) {                       // 이름이 비어 있으면
        console.log("이름을 입력하세요.");
        return;                         // 여기서 함수 끝
    }
    console.log(sName + " 등록 완료");   // 여기까지 오면 이름이 있다는 뜻
}
register("");         // 이름을 입력하세요.
register("민수");     // 민수 등록 완료
.

@kw 콜백 함수(Callback Function)
d: 다른 함수에 값처럼 건네서, 받은 쪽이 나중에 불러 주는 함수예요. 언제, 몇 번 부를지는 받은 쪽이 정해요.
e: 함수도 값이라서 변수에 담거나 다른 함수에 넘길 수 있어요. 함수 이름 뒤에 `()`를 붙이면 지금 실행, 안 붙이면 함수 자체를 건네는 거예요.
c:js
function sayHello() { console.log("안녕"); }

function doTwice(fnTask) {     // fnTask = 건네받은 함수
    fnTask();
    fnTask();
}
doTwice(sayHello);             // 안녕 / 안녕
doTwice(function () {          // 이름 없이 바로 만들어 넘기기
    console.log("바로 만든 함수예요");
});
.
w: 건넬 때 `()`를 붙이면 안 돼요. `doTwice(sayHello())`는 `sayHello`를 지금 실행하고 그 결과(`undefined`)를 건네서 `fnTask is not a function` 에러가 나요.
s: 배열 메서드(`find`, `filter`, `forEach`)에 넘기는 함수도 모두 콜백 함수예요.

@kw 화살표 함수(=>)
d: `function`을 짧게 쓴 모양이에요. 새 기능이 아니라 같은 함수예요.
c:js
const f1 = function (v) { return v + "조"; };   // ① 기본
const f2 = (v) => { return v + "조"; };         // ② function 대신 =>
const f3 = (v) => v + "조";                     // ③ return 한 줄이면 { }와 return 생략
const f4 = v => v + "조";                       // ④ 매개변수가 하나면 ( )도 생략
f4(2);    // "2조"
.
t:
(매개변수1, 매개변수2) => 돌려줄 값
매개변수 => 돌려줄 값
.
e: `v => v + "조"`는 "v가 들어오면 v + '조'를 돌려줘요"라고 읽어요.

@kw 배열 메서드
d: for문이 하던 찾기, 거르기 같은 일에 이름을 붙인 도구예요. 괄호 안에 "각 항목에 할 일"을 콜백 함수로 넘겨요.
e: 안에서는 똑같이 반복해요. 반복문이 눈에 안 보일 뿐이에요. 6부 이후 코드에서 계속 나와요.
c:js
const aStudents = [
    { name: "민수", group: 1, score: 85 },
    { name: "지아", group: 2, score: 92 },
    { name: "도윤", group: 1, score: 58 },
    { name: "서연", group: 3, score: 77 }
];
const aGroups = [1, 2, 3];

aGroups.includes(3);                               // true      있는지 확인
aStudents.find(s => s.name === "도윤");            // { name: "도윤", ... }   첫 항목
aStudents.findIndex(s => s.name === "서연");       // 3         번호 (없으면 -1)
aStudents.filter(s => s.group === 1);              // 1조 학생 둘을 모은 새 배열
aStudents.forEach((s, i) => console.log(i, s.name));   // 하나씩 실행만
aStudents.map(s => s.name);                        // ["민수", "지아", "도윤", "서연"]
.
tb:
하고 싶은 일 | 메서드 | 돌려주는 값
값이 들어 있는지 확인 | `includes(값)` | `true` / `false`
조건에 맞는 첫 항목 | `find(콜백 함수)` | 그 항목 (없으면 `undefined`)
조건에 맞는 첫 항목의 번호 | `findIndex(콜백 함수)` | 번호 (없으면 `-1`)
조건에 맞는 것 전부 | `filter(콜백 함수)` | 새 배열 (없으면 `[]`)
하나씩 실행만 | `forEach(콜백 함수)` | 없음
하나씩 바꿔서 새 배열 | `map(콜백 함수)` | 새 배열
.
s: `s => s.name === "도윤"`의 `s`는 학생 한 명을 부르는 임시 이름이에요. 마음대로 지어도 돼요.
w: `find`의 결과는 바로 쓰기 전에 `undefined`인지 확인해요. 못 찾으면 다음 줄에서 `Cannot read properties of undefined` 에러가 나요.
w: `includes`는 종류까지 비교해요. `aGroups.includes("3")`은 `false`예요.
s: 이 메서드들은 원래 배열을 바꾸지 않아요. 새 배열이나 값을 돌려줄 뿐이에요.
s: `map`으로 객체를 바로 돌려줄 때는 `n => ({ code: n })`처럼 괄호로 한 번 더 감싸요. 괄호가 없으면 `{ }`를 함수 몸통으로 읽어요.

@kw 배열 vs 객체
d: 배열은 처음부터 하나씩 비교해서 찾고, 객체는 키로 바로 찾아가요.
c:js
aStudents.find(s => s.name === "도윤");     // 배열: 하나씩 비교해요

const oScoreMap = { "민수": 85, "지아": 92, "도윤": 58 };
oScoreMap["도윤"];                           // 객체: 키로 바로 가요
.
s: 데이터가 수백 개 정도면 둘 다 충분히 빨라요. 읽기 쉬운 쪽을 고르면 돼요.
